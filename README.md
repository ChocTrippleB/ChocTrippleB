## What I bring to a team

- **Backend and APIs.** ASP.NET Core Web API and MVC in layered architectures (controller, service, repository), Entity Framework, SQL Server and PostgreSQL, JWT with role-based access control, SignalR for real-time features.
- **Web applications.** React and Next.js front ends with Tailwind CSS, taken from Figma designs to production.
- **Software design.** Object-oriented design with GoF patterns in real code: Observer, Proxy, State, Strategy, and domain state machines that keep business rules out of controllers.
- **Shipping and operating.** Docker, AWS, Azure DevOps and on-premise deployments, plus the support that keeps systems running after launch.
